# Code Humanizer

A Visual Studio Code extension designed to make AI-generated code look more natural and human-written, complete with a live interactive preview panel and configurable style options.

## Features

- **Live Interactive Preview (`Code Humanizer: Open Live Preview`):** Edit or paste code and watch the humanized output update in real time as you adjust intensity, author style, and options.
- **Humanize Selection (`Code Humanizer: Humanize Selection`):** Transform selected code directly inside your editor.
- **Configurable Intensity:** Choose between `subtle`, `balanced`, and `heavy`.
- **Author Personas:** Choose between `clean-standard`, `pragmatic`, and `beginner` (including short variable names when enabled).
